# 🚗 Prova de Refatoração - Sistema de Veículos

Repositório dedicado à atividade de refatoração orientada a objetos em Java, aplicando conceitos de encapsulamento, regras de negócio em métodos de ação e boas práticas de modelagem.

---

## 📂 Estrutura do Projeto

```text
prova-refatoracao-bryan/
├── diagrama-veiculo-refatorado.png   # Diagrama de Classes UML PNG (Astah)
├── diagrama-veiculo-refatorado.asta   # Diagrama de Classes UML (Astah)
└── src/
    ├── Veiculos.java                 # Classe modelada com regras de encapsulamento e combustível
    └── Main.java                     # Classe de execução e testes dos cenários
```

---

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** Java 
* **IDE:** IntelliJ IDEA / Eclipse
* **Controle de Versão:** Git & GitHub

---

## 📐 Diagrama de Classes
*(Adicione seu diagrama UML exportado do Astah na raiz do projeto com o nome `diagrama-veiculo-refatorado.png` para exibi-lo aqui)*

> *O diagrama ilustra os atributos privados da classe `Veiculos`, os métodos públicos de abastecimento/consumo e as restrições de acesso implementadas.*

## 🚀 Como Executar o Projeto

1. Clone o repositório na sua máquina:
   ```bash
   git clone https://github.com
   ```
2. Abra o projeto na sua IDE Java favorita (IntelliJ ou Eclipse).
3. Execute a classe `src/Main.java`.
